## How to use this log

1. Run the handoff prompt for a section in Claude Code (against this repo).
2. Paste the returned report back into the orchestrating chat.
3. The orchestrator reviews the report, de-duplicates, and appends confirmed
   findings to the **Master findings table** below with a stable ID.
4. We re-triage `Priority` as a batch once all sections are in.

## 🚦 Launch-readiness verdict (all 12 sections reviewed, 2026-06-23)

**Overall:** Zerro is fundamentally well-engineered. The money path (server + client), secret handling, Sparkle update integrity, telemetry privacy, and Dev-Mode command-execution safety are all sound and were independently verified. The launch-blockers are **contained, non-architectural fixes** concentrated in four areas: cost-abuse exposure, Dev-Mode data-safety + privacy, a payments-config gap, and web privacy/marketing.

**Scorecard:** ~115 findings logged · **7 launch-blockers** (1 conditional) · ~15 cheap pre-launch one-liners · ~8 pre-launch decisions/confirmations · remainder post-launch. Nothing rated catastrophic or architectural.

### 🔴 Launch-blockers — fix or consciously accept before release
1. **X-01** — farmable trials × unmetered `/convert`+`/dev_transcribe` × no global spend cap → unbounded provider spend. *Fix:* meter free endpoints against the per-grant pool + a coarse org-wide daily spend cap/alert.
2. **A-04** — generation slot reclaimed mid-flight (180s stale < ~480s hold) → cap-1 broken → concurrent overspend. *Fix:* one-line stale-window bump / heartbeat.
3. **G-01** — failed Dev-Mode revert discards the checkpoint → loses the user's uncommitted work, edits unrevertible. *Fix:* retain checkpoint until a verified restore.
4. **F-01** — Dev-Mode anchor crops + OCR bypass the Redactor → secrets egress even with redaction ON (no server backstop). *Fix:* route crops/OCR through the Redactor.
5. **K-01** — LemonSqueezy license key leaks to PostHog on `/checkout-complete`. *Fix:* clean-URL + PostHog scrub + Referrer-Policy.
6. **K-02** — landing page falsely claims local-only processing. *Fix:* scope locality claims to BYOK + add the best-effort caveat.
7. **A-01** *(conditional)* — `LS_VARIANT_YEARLY` unset → yearly subscribers starved after ~1 mo. **Blocker only if yearly ships at launch.** *Fix:* set + validate the env var; confirm the LS yearly variant is live.

### 🟡 Cheap pre-launch hardening (one-liners / contained)
D-01 revoke anon cron · C-10 force RLS on `affiliate_referrals` · B-03/B-04 input + output caps · E-01 deeplink confirm + no-overwrite · E-02 reconcile 40-vs-30 credits · G-02 process-group teardown · I-01 protect + clear-history store · I-02 idle-gate auto-update · J-01 byte-lock Dev prompt · J-02 OpenAI 403→auth · K-03 remove dead `/auth` · K-04 security headers · L-01/02/03 CI supply-chain.
