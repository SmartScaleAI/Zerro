# Security Policy

## Reporting a vulnerability

**Do not open a public issue for a security vulnerability.**

Please report vulnerabilities privately through GitHub's private
vulnerability reporting:

- <https://github.com/SmartScaleAI/smartscale-zerro/security/advisories/new>

If that is unavailable to you, email
[support@getzerro.app](mailto:support@getzerro.app) with "SECURITY" in the
subject line.

We will make a good-faith effort to acknowledge and investigate reports
promptly, but we do not commit to a specific response deadline.

## What to include

Enough detail for us to understand and reproduce the issue: the affected
component (macOS app or website), the version you tested, and the
conditions required.

**Never include real secrets or personal data in a report:**

- No API keys or provider credentials.
- No license keys.
- No screen recordings or screenshots containing private information.
- No personal data belonging to you or anyone else.

Use placeholder values and redacted captures instead.

## Supported versions

Security fixes ship in new releases of the current release line. Older
releases do not receive backported fixes; update to the latest release to
receive security updates. Self-built and community builds are outside the
scope of official security support, though we still want to hear about
vulnerabilities in the shared source code.

## Disclosure

Please give us a reasonable opportunity to fix a vulnerability before
disclosing it publicly, and avoid publishing step-by-step exploitation
details for unpatched issues.
